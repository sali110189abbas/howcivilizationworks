Privacy Policy

How Civilization Works · "HCW Uploader" · Effective 8 October 2026

Who we are

How Civilization Works is an independent YouTube channel (@howcivilizationworks). "HCW Uploader" is our private, internal software tool. We use it only to manage our own YouTube channel. It is not offered to, or used by, members of the public.

What the tool does

HCW Uploader uses the YouTube API Services to upload videos to our own channel, set their titles, descriptions, tags, thumbnails and captions, change their privacy status, manage our own playlists and comments, and read our own channel's statistics.

What data it accesses

  • Only data belonging to our own YouTube channel, accessed with the channel owner's explicit permission through Google's OAuth sign-in.
  • OAuth scopes: youtube.upload and youtube.force-ssl.
  • We do not access, collect or store personal data about viewers or any other YouTube users.

How data is stored and protected

The access token Google issues is stored only on the channel owner's own computer, in a private folder that is never shared, published or uploaded. We do not run servers that store YouTube data.

Retention and deletion

  • We keep only the OAuth access token needed to act on our own channel. We do not store copies of YouTube API data other than our own videos' metadata and our own channel statistics used for internal reports.
  • Any YouTube API data we store is refreshed or deleted within 30 days, in line with the YouTube API Services Developer Policies.
  • When access is revoked, or the tool is retired, the stored token and any stored API data are deleted.
  • To request deletion of any data related to this tool, email the contact address below; we respond within 7 days.

Sharing

We do not sell, rent, share or transfer any data obtained through the YouTube API Services to anyone.

Revoking access

Access can be revoked at any time from the Google account security settings: myaccount.google.com/permissions.

YouTube and Google

HCW Uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Changes

If this policy changes, we will update this page and its effective date.
